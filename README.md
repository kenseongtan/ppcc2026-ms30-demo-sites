# Demo agency websites – MS30, PPCC 2026

Look-alike public lookup websites for a computer-use demo in the session **MS30 · Build, Reuse, and Act in Copilot Studio** at the Power Platform Community Conference 2026.

**Everything here is fictional.** The agencies (Sagebrush State Contractors Board, Mesa County, City of Desert Springs, Southern Basin Health District), companies, people, license numbers, and inspection results are invented. They are not affiliated with any government agency.

| Site | Path |
|---|---|
| Contractor license search | `/contractors/` |
| County business license search | `/county/` |
| City business license inquiry | `/city/` |
| Restaurant inspection search + data downloads | `/health/` |

Static HTML, CSS, and JavaScript; no external dependencies. Data is generated with a fixed seed by `data/generate.js` in the source folder.
