About this site

This website is a fictional demo created for the session MS30 at the Power Platform Community Conference 2026. The State of Sagebrush, its Contractors Board, and every company, person, and license number shown are invented. The site is modeled on the layout of public contractor-license lookups so that a computer-use agent can be demonstrated safely.

It is not affiliated with any government agency. Do not rely on it for any purpose.
